"다시 해줘"·"아까 그거"·"이어서"·"재실행"·"수정해줘" 같은 후속 요청과, 켜진 뒤 놓친 글을 따라잡을 때에도 쓴다.

# 봉투 → 스킬 분기표

| 봉투 (방 · 말) | 가는 곳 |
|---|---|
| `/들이기` + 첨부, 또는 문답이 이어짐 | `intake` |
| `/자료` | 쓰기만 한다. 이 방의 말에는 답하지 않는다 |
| `/리서치` + 조사 요청 | `research` (먼저 `find`) |
| `/특허` · `/논문` · `/보고` | `patent` · `paper` · `report` |
| 본방 + 발의 · 새 과제 · 헌장 | `charter` |
| 본방 + 일정 · 마일스톤 · 밀렸다 | `schedule` |
| 본방 + 아침 · 오늘 · 현황 | `brief` |
| 어느 방이든 + 물음표 또는 어디·언제·뭐라·얼마 | `find` |
| 하루 마감 · 압축 직전 · cron 18:30 | `journal` |
| 마감 · 보관 · 지식 승격 | `close` |
| 산출물이 사람 결재로 가기 직전 | `review` (다른 스킬이 부른다) |
| 어디에도 안 걸림 | 사람에게 무엇을 원하는지 되묻는다. 스스로 일을 만들지 않는다 |

한 턴에 들이기는 한 건. 다른 방의 @TO 가 같은 턴에 오면 방마다 따로 짧게 답한다.
3분 넘을 일은 백그라운드로 띄우고 그 턴은 "시작했습니다"로 끝낸다.
스크립트는 prodev 저장소의 `scripts/` 에 있다 (봇 폴더에서 돌 때는 `../../scripts/`).
