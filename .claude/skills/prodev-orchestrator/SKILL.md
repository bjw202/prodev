# 봉투 → 스킬 분기표

위에서부터 본다. 먼저 걸린 줄에서 멈춘다.

| 봉투 (방 · 말) | 가는 곳 |
|---|---|
| **본방 + 첨부** | 답 대신 안내 한 줄: "파일은 files 방에 올려주시면 거기서 읽고 여쭙겠습니다." **읽기 시작하지 않는다** |
| `files` + 첨부 + **시키는 말** (채워 줘 · 써 줘 · 뽑아 줘 · 준비) | `report` · `paper` · `patent` — 보고 양식 · 논문 초안 · 특허 자료 |
| `files` + 실험 자료 첨부, 또는 문답이 이어짐 | `intake` (문답 중의 물음도 intake 의 것) |
| 어느 방이든 + **시키는 말** (특허 · 논문 · 보고) | `patent` · `paper` · `report` |
| 어느 방이든 + **바깥을 알아봐 달라는 말** (조사해 줘 · 알아봐 줘 · 문헌 · 규격 · 왜 그런가 · 남들은) | `research` (먼저 `find`) |
| 어느 방이든 + **물음** — 물음표 또는 어디·언제·뭐라·얼마·누구·몇 | `find` |
| 발의 · 새 과제 · 헌장 | `charter` |
| 하루 마감 · 오늘 정리 · **일지** · 압축 직전 · cron 18:30 | `journal` (`오늘` 이 들어가도 일지가 먼저다) |
| 오늘 · 현황 · 브리핑 · cron 08:00 | `brief` |
| 일정 · 마일스톤 · 기한 · 밀렸다 · 할 일 | `schedule` |
| 과제가 끝남 · 방 보관 · 지식 승격 | `close` |
| 산출물이 사람 결재로 가기 직전 | `review` (다른 스킬이 부른다) |
| 어디에도 안 걸림 | 사람에게 무엇을 원하는지 되묻는다. 스스로 일을 만들지 않는다 |

방은 둘뿐이다 — 본방 `prodev-<과제>` 와 `prodev-<과제>/files` (ADR-022).
**어느 방에서든 답한다.** 방을 이유로 답을 거부하거나 다른 방으로 보내지 않는다.
위 표의 첫 줄, 본방에 올라온 파일 안내가 **유일한 예외**다.

**켜진 뒤·압축된 뒤 첫 글은 "이어서 합니다" 한 줄로 연다.** 방을 짚고, 하던 실이 있으면 그것을 한 줄로 잇는다 (재생에서 빠졌다).
시키는 말 줄이 물음보다 앞이되 **시키는 말이 있을 때만**이다: "그 숫자 어디서 나왔지"는 `find` 로 간다.
한 턴에 들이기는 한 건 — 다른 방의 @TO 가 같은 턴에 오면 방마다 따로 짧게 답하고, 3분 넘을 일은 백그라운드로 띄워 그 턴을 "시작했습니다"로 끝낸다.
스크립트는 prodev 저장소의 `scripts/` 에 있다 (봇 폴더에서 돌 때는 `../../scripts/`).
