# analysis — 분석과 DOE

## 언제

이미 들인 자료(`inbox/` · 카드)를 놓고 **숫자를 더 뽑아야 할 때.**
`intake` 가 "이렇게 읽었습니다"까지 갔다면, 여기는 **"그래서 갈리느냐"** 를 본다.

`intake` 와 다른 점: 들이기는 **받은 것**을 적고, 분석은 **만든 것**을 남긴다.
그래서 자리도 짝이다 — `inbox/YYYYMMDD-<slug>/` 옆에 `analysis/YYYYMMDD-<slug>/`.

## 먼저 — 이미 한 것이 있나

**분석을 시작하기 전에 찾는다.**

```
node scripts/find.js <분석 이름> <자료 이름> --limit 10
ls analysis/
```

있으면 **새 폴더를 만들지 않는다.**

| 무엇을 물었나 | 하는 것 |
|---|---|
| 같은 물음 | **앞 카드를 댄다.** 결론 한 줄과 `analysis/` 경로를 그대로 보인다 |
| 같은 물음 · 자료가 늘었다 | 있는 `run.py` 를 **그대로 다시 돌린다.** 새로 짜지 않는다 |
| 다른 물음 | 새 폴더. 다만 `run.md` 1번 칸에 앞 분석 경로를 적는다 |

**이 한 걸음이 이 스킬의 목적이다** — 다음에 또 짜지 않는 것.

## 하는 일 — 다섯 걸음

### 1. 무엇을 알고 싶은지 한 줄로 되짚는다

```
<이 자료로> <무엇이> <어떻게 갈리는지> 보려는 것이 맞습니까?
```

물음이 문장이 안 되면 분석도 안 된다. **여기서 한 줄 확인하고 넘어간다.**

### 2. 모형을 고르게 한다 — 이 스킬의 유일한 관문

**봇은 그럴싸하게 틀린 모형을 고른다.** 그래서 여기만 사람이 정한다.

후보 **두셋**을 근거와 함께 내고 하나를 고르게 한다:
```
모형 후보입니다.
1. <모형> — <왜 맞을 수 있나> · <무엇을 가정하나>
2. <모형> — <왜 맞을 수 있나> · <무엇을 가정하나>
어느 쪽으로 갈까요?
```

DOE 의 **인자 · 수준 · 제약**도 같은 자리다. 그것도 사람이 정한다.

**코드를 짜는 데는 관문이 없다.** 모형이 정해지면 바로 짠다 — 물음을 늘리지 않는다.

### 3. `analysis/<YYYYMMDD>-<slug>/run.py` 를 짠다

- 입력은 **경로로 박는다.** `inbox/` 는 불변(SHA-256)이라 반년 뒤에도 같은 파일을 읽는다
- 그림은 `tmp/` 에 낸다. **커밋하지 않는다** — 코드에서 다시 나온다
- 난수를 쓰면 **초기값(seed)을 코드 안에 고정한다**

**꾸러미가 없으면 지어내지 않는다.** `scipy`·`statsmodels`·`pandas` 는 사람이 미리 깐다 (`docs/launch.md` 10.4).
없으면 *"이 기계에 statsmodels 가 없어 회귀를 못 돌립니다"* 라고 말하고 멈춘다. 손으로 계산한 숫자를 내놓지 않는다.

### 4. `run.md` 여섯 칸을 채운다

**칸은 측정법이 무엇이든 같다.** 달라지는 것은 2·3 뿐이다.

```markdown
# <분석 이름>
언제 <날짜> · 누가 <사람 이름> · 자료 <inbox 경로>

## 1. 무엇을 알고 싶은가
<사람이 확인해 준 한 줄>

## 2. 어떤 가정을 깔았나
모형 <무엇> (사람이 고름, <날짜>) · 임계값 <값> · 정규성 <봤나 · 어떻게>

## 3. 코드
run.py · seed <값> · python <판> · <꾸러미> <판> · <꾸러미> <판>

## 4. 숫자 + 검증치
<결과 값> · <잔차 | χ² | 신뢰구간 | 경계 겹친 그림 경로>

## 5. 물리적 해석 (추정)
<말> — 근거: 4번의 <어느 숫자>

## 6. 이 해석을 뒤집을 수 있는 것
<무엇을 더 재면 틀린 것으로 드러나는가>
```

**3번 칸이 없으면 재현성 검수가 성립하지 않는다.** 반년 뒤 숫자가 달라졌을 때 봇이 틀린 것인지
라이브러리가 바뀐 것인지 가를 수 없다. seed 와 판을 안 적었으면 그 분석은 안 한 것과 같다.

**2번과 6번을 비우지 않는다.** 가정을 숨기고 결론만 말하면 틀렸을 때 어디서 틀렸는지 알 수 없다.

### 5. 카드를 만든다 — 선택이 아니다

```
node scripts/index.js next E     → cards/E-00NN.md
node scripts/index.js
```

**`analysis/` 는 검색에 안 걸린다.** 찾기 층 여섯은 코드에 고정이고 `analysis/` 는 그 어느 층도 아니다
(`find.js` 의 층 순서는 부르는 쪽이 바꾸지 못한다). **카드(2층)에 결론 한 줄과 경로가 있어야 다음에 찾는다.**

카드에 반드시 들어가는 셋: **결론 한 줄 · `analysis/<폴더>/` 경로 · 쓴 모형과 임계값.**
`aliases` 에 사람이 부를 법한 말을 넣는다 ("유의차" · "갈리나" · "공정능력").

그리고 커밋한다 — `run.py` · `run.md` · 카드. 그림은 `tmp/` 라 안 들어간다.

## 숫자와 해석을 가른다

- **숫자는 스크립트만.** 카드와 `run.md` 4번 칸에 들어가는 수치는 **스크립트 출력에서 온 것**이어야 한다.
  AI 가 못해서가 아니라 **틀렸을 때 아무도 모르기 때문**이다. p 가 0.04 냐 0.06 이냐가 양산 결정을 가른다
- **해석은 자유롭게 말한다.** 단 둘을 지킨다 — (1) **어느 숫자에서 나온 말인지** 대고 (2) **확인된 사실인지 추정인지** 표시한다

이 구분 없이 "출력만 붙인다"로 못 박으면 봇이 숫자 표만 내고 입을 닫는다. 그것도 일을 안 한 것이다.

## 사람 눈으로만 확인되는 것

| | 예 | 그래서 |
|---|---|---|
| 기계가 스스로 확인한다 | 피팅(잔차 · χ²) · t 검정 · 회귀 · Cpk | 즉석에서 짜도 된다. 안전장치가 출력 안에 있다 |
| **사람 눈으로만 확인된다** | 이미지에서 입자 · 기공 · 두께 재기 | 숫자만 내면 안 된다 |

이미지 계측은 **원본 위에 검출 결과를 겹친 그림을 반드시 같이 낸다.** 그림 없이 숫자만 내지 않는다.

## 못 하는 것 — 말하고 멈춘다

**측정 자체의 결함은 못 알아챈다.** 저주파 드리프트 · 차징 아티팩트 같은 것은 자료만 보면 진짜 신호와 구분이 안 된다.
숫자가 이상하면 *"자료가 이상한 것일 수도 있습니다"* 를 6번 칸에 적고, 대신 판정하지 않는다.

## 되풀이된 방법이 굳는 자리

같은 분석을 또 하게 되면 사람이 **"앞으로 이렇게 해"** 라고 말한다. 그때 `analysis/methods/<이름>.md` 로 굳는다
(굳는 길 — `CLAUDE.md`). **봇이 스스로 굳히지 않는다.** 측정법마다 템플릿을 미리 만들지도 않는다 —
측정법은 수십 가지고 과제가 바뀌면 또 나온다. **틀린 템플릿이 즉석 코드보다 위험하다:**
즉석 코드에는 "방금 짠 것"이라는 경계심이 붙어 사람이 한 번 보지만, 템플릿은 검증된 것처럼 보여서 아무도 안 본다.

## 사람이 정하는 자리

- **모형 고르기** (걸음 2). DOE 의 인자 · 수준 · 제약도 여기
- **방법을 굳힐지** — 사람이 "앞으로" 라고 말할 때만

## 부르는 것

`scripts/find.js` (이미 한 것 찾기) · `scripts/index.js` (카드 번호) · `python3` · `git`.
출력이 커서 대화를 덮을 자료는 `data-reader` 에게 먼저 읽힌다.

## 다시 불렸을 때

- **같은 물음이면 새 폴더를 만들지 않는다** (위 "먼저" 절).
- "수를 늘리면?" — 있는 `run.py` 를 그대로 돌리고 `run.md` 4·5·6 만 고친다. 2번 칸(가정)이 바뀌면 그때는 새 폴더다.
- "다른 모형으로" — 새 폴더다. 앞 모형으로 낸 결론이 있다는 것을 알린다. **앞 폴더를 덮어쓰지 않는다.**

## 걸리는 자리

| 일 | 하는 것 |
|---|---|
| 꾸러미가 없다 | 없다고 말하고 멈춘다. 손으로 계산하지 않는다 |
| 표본이 너무 적다 | 숫자를 내되 **"이 수로는 경향을 말할 수 없다"** 를 5번이 아니라 **6번 칸**에 적는다 |
| 사람이 모형을 안 고른다 | 기다린다. 봇이 고르고 넘어가지 않는다 — 여기가 유일한 관문인 까닭이 그것이다 |
| 자료가 `inbox/` 밖에 있다 | 먼저 `intake` 로 들인다. 불변이 아닌 파일을 입력으로 박으면 재현이 안 된다 |
| 그림이 안 그려진다 | `matplotlib` 이 없다고 말하고 숫자만 낸다. 죽지 않는다 |
| 카드를 만들기 귀찮다 | 만든다. 안 만들면 **이 분석은 다음 주에 없는 것이 된다** |
