# report — 보고

## 언제

`/보고` 방. PL 이 주간·월간·경영진 보고를 말할 때.

## 왜 포맷 파일을 받나

회사마다 보고 서식이 있고, 사람은 그 서식으로 결재를 받는다.
비서가 예쁜 서식을 새로 만들면 사람이 다시 옮겨 적어야 한다. 그래서 **칸을 바꾸지 않는다.**
포맷 파일이 없으면 만들지 않고 청한다.

## 하는 일 — 네 걸음

### 1. 기간과 포맷을 확인한다

```
포맷: <경로> — 없으면 청한다
기간: <시작>~<끝> — 사람이 "이번 주" 라 하면 날짜로 바꿔 되짚는다
```

### 2. 방향 셋을 묻는다

기간의 재료를 훑고 방향 셋을 만들어 **하나를 고르게 한다:**
```
이 기간에서 세울 수 있는 방향 셋입니다.
1. <성과 중심> — <무엇을 앞세우나>
2. <위험 중심> — <무엇을 앞세우나>
3. <일정 중심> — <무엇을 앞세우나>
어느 쪽으로 갈까요?
```
방향이 정해지지 않은 보고서는 사실의 나열이 되고, 읽는 사람이 무엇을 해야 할지 모른다.
셋을 넘기지 않는다.

### 3. 칸을 채운다

`report-writer` 를 부른다.
넘기는 것: 포맷 경로 · 기간 · **사람이 고른 방향** · 과제 폴더 · 산출 경로 `report/<기간>.md` ·
쓸 수 있는 자료(일지 폴더 · `schedule.md` · 카드 목록) · 끝 조건("숫자마다 카드 출처가 있고 그 카드의 값과 같다").

**숫자마다 카드 출처를 단다.** 출처 없는 숫자는 지우지 않고 목록으로 올라온다 —
그것을 사람에게 물어야 하기 때문이다.

끝나면 `reviewer` (다른 문맥) 가 숫자를 다시 세고 카드에 대조한다 → `report/<기간>.md.review.md`.

### 4. 사람에게 낸다

방에 올리는 것:
```
보고서 <기간> · 방향 <고른 것>
채운 칸 <N>/<N>
출처 없는 숫자 <N>개: <칸 이름과 값>   ← 있으면 반드시 보인다
검토: 통과 | 불통과 | 검증 불가
경로: report/<기간>.md
```
**보고서 파일과 검토 판정 파일을 방에 첨부한다.** 경로는 옆에 (ADR-020).
보고서는 사람이 그대로 결재에 쓰는 것이라, 열러 가게 하지 않는다.

출처 없는 숫자를 조용히 넘기지 않는다. 경영진 보고에서 근거 없는 숫자 하나가 나중에 가장 비싸다.

## 사람이 정하는 자리

- **방향 선택** (셋 중 하나)
- **발송 결재 — PL 이 한다.** 결재 글과 헌장의 PL 을 맞춰 보는 것은 기계가 한다.

## 부르는 것

`report-writer` (칸 채우기) · `reviewer` (검토) · `scripts/find.js` · `scripts/chat.js`

## 다시 불렸을 때

- 앞 보고서와 `.review.md` 를 읽는다.
- 칸 하나만 고치라 하면 그 칸만 고친다. 전체를 다시 채우지 않는다.
- 기간이 바뀌면 새 파일을 만든다. 앞 기간 파일을 덮어쓰지 않는다.
- 방향을 바꾸면 다시 채우되, 앞 방향으로 낸 것이 있다는 사실을 알린다.

## 걸리는 자리

| 일 | 하는 것 |
|---|---|
| 포맷 파일이 없다 | 서식을 지어내지 않는다. 청한다. 급하면 앞 기간 보고서를 서식으로 쓸지 묻는다 |
| 포맷을 못 읽는다 (xlsx·hwp) | 형식과 까닭을 말하고 다른 형식을 청한다 |
| 기간에 자료가 거의 없다 | 빈칸을 빈칸으로 둔다. 그럴듯한 말로 메우지 않는다 |
| 카드와 일지의 숫자가 다르다 | 카드를 쓰고, 다르다는 것을 사람에게 보인다 |
| 발송이 막혔다 | 막은 이유 한 줄이 온다. 그 자리를 고친다. 우회하지 않는다 |
