# research — 바깥 자료 조사

## 언제

`/리서치` 방, 또는 어느 방에서든 "알아봐 달라"는 말. 결과 논의 중에 모르는 것이 나왔을 때.

## 왜 허락을 먼저 받나

조사는 시간과 돈이 든다. 그리고 사람이 원한 물음과 봇이 이해한 물음이 어긋나면 그 값이 전부 버려진다.
그래서 **물음을 문장 하나로 적어 보이고** 허락을 받는다. 이 한 번의 왕복이 헛조사를 막는다.
비서는 스스로 조사를 시작하지 않는다.

## 하는 일 — 다섯 걸음

### 1. 먼저 안을 본다

```
node scripts/find.js <말> --limit 10
```
이미 있으면 조사하지 않는다. 찾은 것을 출처와 함께 답하고 끝낸다.
겹치는 것이 있으면 그 카드 번호를 다음 걸음에 넘긴다 (같은 조사를 두 번 하지 않는다).

### 2. 물음을 적고 허락을 구한다

방에 세 줄:
```
안에는 <있음/없음> — <찾은 카드 번호 또는 "없습니다">
물음: <한 문장>
범위: <어디까지 볼까 — 문헌·규격·웹, 기간, 분야>
진행할까요?
```
사람이 물음을 고치면 고친 대로 간다.

### 3. 조사한다 (백그라운드)

허락이 오면 `researcher` 를 **백그라운드로** 띄우고 그 턴은 "시작했습니다" 한 줄로 끝낸다.
넘기는 것: 물음 한 문장 · 허락받은 범위 · 이미 아는 카드 번호 · 과제 폴더 · 산출 경로 `research/<주제>.md` ·
끝 조건("결론의 문장마다 출처가 붙는다").

긴 턴은 다른 사람의 물음을 막는다. 세션은 한 번에 한 턴만 돈다.

### 4. 검토를 받는다

`researcher` 가 끝나면 `reviewer` 를 부른다 (다른 문맥). 판정은 `research/<주제>.md.review.md` 에 남는다.
불통과면 짚은 자리를 `researcher` 에게 되돌려 고친다. 검토를 건너뛰고 사람에게 내지 않는다.

### 5. 브리핑하고, 몇 턴 뒤 카드로 굳힌다

방에 열 줄:
```
물음: <한 문장>
결론 3줄 (문장마다 출처)
못 확인한 것 1줄
검토: 통과 | 불통과 | 검증 불가
경로: research/<주제>.md
```

대화가 몇 턴 오간 뒤, 사람이 "그걸로 하자"고 하면 **카드 R** 로 굳힌다:
`node scripts/index.js next R` → `cards/R-0003.md` → 위키 갱신 → `node scripts/index.js` →
`/자료` 방에 글 → 커밋.

굳히기 전에는 리서치 문서만 있고 카드는 없다. 대화 중인 것을 카드로 만들지 않는다.

## 사람이 정하는 자리

- **조사 시작 허락** (물음과 범위)
- **카드 굳힘** — "그걸로 하자"

## 부르는 것

`researcher` (조사) · `reviewer` (검토) · `scripts/find.js` · `scripts/index.js`

## 다시 불렸을 때

`research/<주제>.md` 가 있으면 읽는다. 사람이 더 알아봐 달라 하면 **새 물음만** 적어 허락을 받고,
같은 파일에 절을 더한다. 앞 조사를 다시 하지 않는다.
카드 R 이 이미 있는데 결론이 바뀌면 덮어쓰지 않는다 — 새 카드를 내고 앞 것을 `void` + `supersedes`.

## 걸리는 자리

| 일 | 하는 것 |
|---|---|
| 사람이 허락 없이 바로 결과를 원한다 | 물음 한 문장만 확인받고 간다. 확인 없이는 시작하지 않는다 |
| 조사가 빈손이다 | 빈손도 결과다. 무엇을 어떤 말로 찾았는지와 함께 알린다 |
| 검토가 불통과다 | 사람에게 브리핑하기 전에 고친다. 두 번째도 불통과면 그 사실을 브리핑에 적고 사람 판단을 청한다 |
| 물음이 너무 크다 | 쪼개서 첫 조각만 허락을 청한다. 큰 물음 하나는 큰 헛조사가 된다 |
