# 판정 기록 사본 (evidence)

meta 가 관문마다 **직접 돌려 센** 결과다. 원본은 `../meta/prodev-review/runs/` 에 있고 여기 있는 여덟은 **글자 그대로의 사본**이다 (sha256 이 같다).

**왜 사본을 두나.** 작업판을 회사로 옮기면 **커밋 · PR · 이슈 이력은 안 간다. 파일만 간다.** 그런데 `ADR.md` 와 `docs/log.md` 의 판정 근거가 전부 `../meta/…/runs/` 를 가리키고 있어서, 그 폴더가 같이 넘어가지 않으면 **"이 결정이 무엇을 보고 내려졌나" 에 답할 수 없게 된다.**

**고치지 않는다.** 사본은 meta 의 기록이지 prodev 의 문서가 아니다. 내용이 낡아 보여도 그대로 둔다 — 그때 무엇을 쟀는지가 여기 남아야 한다. 새 판정은 새 파일로 온다.

| 파일 | 무엇을 쟀나 |
|---|---|
| `2026-09-10-T1M.md` | 1단계 관문 — 뼈대와 부품 |
| `2026-09-10-T2M.md` · `2026-09-10-T2M-2.md` | 2단계 관문 — 하네스(스킬 · 에이전트), 1차와 2차 |
| `2026-09-10-T3M.md` | 3단계 관문 — 첫 기동과 시나리오. 찾기 62.5% |
| `2026-09-11-search.md` | 검색 안정성 1차 (ADR-026~029). 찾기 87.5% |
| `2026-09-11-search-2.md` | 검색 안정성 2차 (ADR-030). 찾기 **16/16** |
| `2026-09-11-evo-seat.md` | 진화하는 비서 관문 A — 자리 (ADR-031~033) |
| `2026-09-11-evo-path.md` | 진화하는 비서 관문 B — 길 (ADR-034~037) |

`runs/` 의 `.txt` · `.jsonl` · 대본 기록(transcript)은 여기 없다. **판정 문서 여덟만** 옮겼다.
