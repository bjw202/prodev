## 3. 드러난 것 (고침이 아니라 기록)

### 3.1 봇이 잡아낸 meta 의 fixture 흠 둘

- 일지 fixture 의 `E-0002` · `E-0003` · `report/2026-W36.md` 가 실물에 없다 — 봇이 새 카드에 같은 번호를 준 뒤 **회의 문서를 쓰기 전에** 물었다 ("그 카드들은 어떻게 된 것입니까"). 근거 없는 번호를 그냥 쓰지 않았다.
- 일지 fixture 의 `p=0.03` · `p=0.008` 을 팀장 보고에서 **"출처 없는 숫자 2개"** 로 가려내고 "근거로 쓰지 않는 편이 낫다"고 적었다. 문서 8절 "숫자는 스크립트만"이 실제로 걸린 자리다.

### 3.2 meta 의 흠 — 재는 판을 더럽힌 것과 대본의 애매함

- `evo-count.js rerun` 이 `rerun.out.txt` 를 **봇의 분석 폴더 안에** 남겼다. 봇이 두 번 알아채고 커밋도 삭제도 하지 않았다. 판정 뒤 도구가 스크래치에 쓰게 고친다.
- 대본 T-4 "이 양식대로"가 T-3 "짧게" 바로 뒤라 봇이 **짧은 두 절**을 "이 양식"으로 읽었다. 실제 PL 이 할 말대로 T-5 에서 바로잡았고 봇은 "무엇을 가리키는지는 안 되물었다"고 스스로 적었다. 대본의 흠이지 봇의 흠은 아니라 B7 에 안 넣었다.
- `templates/주간-보고.md` 를 meta 가 커밋 없이 놓았다. 봇이 "김피엘이 넣은 것"으로 커밋했다(`7bef009`).

### 3.3 봇이 스스로 바로잡은 것 · 먼저 말한 것

- Cpk 를 **Ppk** 로 바로잡았다(부분군 열이 없다) — "보고서에 Cpk 로 적으면 감사에서 걸린다".
- "BSTech 로 몰면 3.3배"를 **2.2배**로 고쳤다(견준 비와 몰기의 이득을 가름). 결정 갈래를 셋에서 여섯으로 늘리며 "돈 안 드는 선택지가 표에 없으면 돈 쓰는 것들 중에서만 고르게 된다"고 적었다.
- 회의 문서에서 "미장착 재고라 수율 원인은 아직 말 못 한다"가 **세 번 빠졌다가 세 번 검토에 걸린 것**을 회고에서 "되풀이"로 올리고, 스킬이 아니라 **스크립트 한 벌**(고친 판과 앞 판을 맞대 사라진 줄 세기)이면 된다고 판별 넷으로 걸렀다 → 스킬 후보 "없음".
- 회고 굳힐 후보 둘째("`tmp/` 에 둔 것은 사라진다")는 시킨 것이 아니라 봇이 알아챈 것이고, "굳힐지는 정하실 자리"라고 넘겼다.

### 3.4 B13 을 ○ 로 읽은 근거 (판정을 가른 칸)

도구 원출력은 근거 없음 **5** · 지어냄 **3** 이었다. 파일로 맞댔다.
- 근거 없음 5 는 도구의 근거 정규식이 `2026-09-01` 꼴만 알고 봇이 쓴 `09-01(#415)` · `W37` · `review.md` 꼴을 몰라서다. 넓힌 규칙으로 다시 세면 1(minidiscord DB 없음 항목)이고, 그 항목도 `none.db` 와 검토 파일의 "검증 불가"를 댄다. → 0.
- 지어냄 3 은 정답지의 "심은 낱말"이 fixture 만 담아서다. 셋은 **오늘 세션의 파일**에 있다 — 검토 불통과 여덟 판 = `2026-W37.md.review.md` 4판(불통과 3) + 팀장보고 6판(불통과 5)(count.txt "검토 파일 판 수") · "고치다 흘림 다섯 번" = 두 검토 파일의 재검토 항목 · "tmp 사라짐" = 일지 09-04(fixture). → 0.
- 관문 A 의 A7(`find` 스킬 이름을 명령으로 센 도구 오탐 3 → 0)과 같은 방식이다. 도구를 고치되 칸과 예측은 안 고친다.
