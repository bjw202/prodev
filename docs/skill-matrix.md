# 스킬 대조표 (T2.3)

하네스가 낸 `.claude/skills/*/SKILL.md` 본문이 설계와 같은가를 칸마다 맞대 본 것이다.
설계 쪽 값은 `../meta/prodev-review/plans/2026-09-10-prodev-design.md` 의 **B 표**와
`design/v2/ARCHITECTURE.md` **6절 흐름**에서 왔다. 어긋나면 **스킬을 고쳤다. 설계는 고치지 않았다.**
설계에 자리가 없어 새로 정한 둘은 `design/v2/ADR.md` ADR-017 에 있다.

맞대 본 것: 트리거 · 입력 · 산출 · 사람 관문 · 부르는 에이전트 · 부르는 스크립트 — 스킬 열둘 × 여섯 칸.

ADR-022(방 둘)로 설계 쪽이 바뀐 칸 셋(`intake` 입력 · `intake` 산출 · `research` 산출)은 코드 PR 에서 `SKILL.md` 를 맞추고 다시 쟀다.
ADR-028(카드 결과 절 규격)로 설계 쪽이 바뀐 칸 하나(`intake` 산출)는 검색 안정성 PR 에서 `SKILL.md` 를 맞추고 다시 쟀다 (2026-09-11).

## 3. 고친 자리 (설계 쪽을 손대지 않고 스킬을 맞춘 것)

| 자리 | 어긋난 것 | 어떻게 맞췄나 |
|---|---|---|
| `brief` 부르는 스크립트 | B 표는 (없음)인데 `chat.js since` 를 쓰고 있었다 | 그 줄을 빼고 "대화를 훑는 것은 journal 의 일" 로 적었다 |
| `close` 부르는 스크립트 | B 표는 `setup.js archive` 뿐인데 `index.js` 를 돌리고 있었다 | 색인을 다시 만들지 않고 이미 있는 `index.json` 을 읽는다 |
| `paper` 산출 | B 표의 "그림" 이 본문에 없었다 | 그림의 자리와 옮기는 때를 걸음 2 에 적었다 (ADR-017) |
| `paper` 산출 | 절 초안과 원고가 한 파일에 섞였다 | `sections/` 는 작업 자리, 통과한 절만 `draft.md` (ADR-017) |
| `schedule` 트리거 | "언제까지였지" 라는 사실 묻기를 갖고 있었다 | 뺐다. 경계 문장에 "지난 일이나 말을 묻는 것은 find" 를 더했다 |
| `brief` 트리거 | "요즘 어디까지 왔나" 에 `어디` 가 들어 있었다 | 뺐다. 오늘·현황·브리핑이 있을 때만 온다고 적었다 |
| `find` 트리거 | 사실 묻기의 낱말이 `누구`·`몇` 까지 덮지 못했다 | 넓혔다. 사실 묻기는 방을 가리지 않고 전부 find 다 |
| 오케스트레이터 분기표 | 방별 행이 물음 행보다 앞이어서 `/보고` 방의 물음이 report 로 갔다 | 물음 행을 방별 행 앞으로 올렸다. 갈래 방 행은 **시키는 말**(써 줘 · 채워 줘 · 뽑아 줘 · 준비)이 있을 때만 그 스킬로 간다 — `/보고` 의 "그 숫자 어디서 나왔지"는 `find` 다 |
| 오케스트레이터 분기표 | `brief` 행이 `오늘` 한 낱말로 `journal` 행보다 먼저 걸려, cron 18:30 의 "오늘 일지" 가 brief 로 갔다 | `journal` 행을 `brief` 행 **위로** 올리고 그 행의 낱말을 `일지` 로 세웠다. `brief` 행에는 cron 08:00 을 적었다 (T2.M 1차) |
| 오케스트레이터 분기표 | `research` 행이 `/리서치` 방으로 묶여, 본방의 "조사해 줘"(물음표도 물음 낱말도 없는 시키는 말)가 어디에도 안 걸렸다 | `research` 행을 방에서 풀어 "어느 방이든 + 바깥을 알아봐 달라는 말" 로 세웠다. `/특허` 의 "선행 조사해 줘" 를 지키려고 갈래 방 행을 `research` 행 **위로** 올렸다 (T2.M 1차) |

`(없음)` 인 칸에 스크립트를 쓴 곳이 둘 남아 있는데, 둘 다 설계의 다른 절이 시킨 것이다:
`schedule` 의 `index.js next D` 와 `research` 의 `index.js next R` 는 **A-3 의 "카드 번호는 `index.js next` 가 준다"** 를 따른 것이다.
B 표의 `(없음)` 은 그 스킬만의 에이전트·스크립트가 없다는 뜻으로 읽었다. 이대로 두면 카드가 번호 없이 만들어진다.
